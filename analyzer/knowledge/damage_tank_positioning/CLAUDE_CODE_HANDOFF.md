# Claude Code에 전달할 지시

첨부 ZIP은 OWcoach의 딜러·탱커 포지셔닝 및 코칭 지식베이스다. 저장소의 CLAUDE.md와 HANDOFF.md를 먼저 읽고 최신 변경을 반영한 뒤 작업해 줘.

1. ZIP의 경로를 유지해 `analyzer/knowledge/damage_tank_positioning/`에 자료를 추가해.
2. 이 폴더의 README.md와 sources.yaml을 읽고 `python analyzer/knowledge/damage_tank_positioning/validate.py`를 실행해.
3. 저장소 루트 README.md에 자료 링크를 추가해. 기존 지원가 기준팩은 유지해.
4. 현재 작업 브랜치에 자료를 커밋·푸시하고 커밋 해시와 변경 경로를 알려줘.

검수 전 draft 자료이므로 approved로 바꾸거나 analyzer/heroes/에 그대로 복사하지 마. 현재 로더가 draft도 활성화하는 점을 확인해. 기존 승인 기준은 유지하고 게임 수치는 overwatch_stats 수집본을 따라. 영웅별 근거 수준을 보존하고 작성자 제안을 검증된 커뮤니티 정답으로 표현하지 마.

자료 추가 후 실제 분석에 연결할 때 필요한 프로필·HUD·프롬프트·후처리 변경을 정리해 줘. 실제 분석 연결은 자료 추가와 구분해 진행해.
