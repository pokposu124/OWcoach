## 실행 검증

- JSON: 영웅 목록 일치, ID 중복 없음, 모든 영웅의 기본 체력 선택 성공, 한국어 표시명/개정 출처 확보.
- 특전: 모든 영웅의 Minor 2개/Major 2개 분류 확인. 한조의 분류 오표기는 공식 페이지로 교정.
- 모드/형태: 디바의 5대5 기본 메카와 파일럿 체력 분리, 트레이서 점멸의 충전 수·충전 시간 분리, 궁극기 비용/쿨타임 분리.
- SQLite: integrity_check=ok, foreign_key_check 오류 0개, JSON과 테이블 개수 일치, 전문 검색 동작.
- 조회 도구: 한국어 영웅 조회, 능력 조회, 효과 검색, 검토 목록 조회 성공.
- 검토 대상 두 능력은 DB의 review_required로 표시.
