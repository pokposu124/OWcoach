# 데이터 출처와 이용조건

주 수집원: **Overwatch Wiki contributors** — https://overwatch.weirdgloop.org/

위키가 표시하는 콘텐츠 라이선스: **Creative Commons Attribution-NonCommercial-ShareAlike 3.0 (CC BY-NC-SA 3.0)** — https://creativecommons.org/licenses/by-nc-sa/3.0/

이 묶음의 위키에서 가져온 설명·효과·조건 및 그 변환물에는 위 출처와 라이선스 표기를 유지합니다. 영웅별 `source.revision_url`에서 사용한 문서 개정을, `source.last_edited_text`와 `fetched_at_utc`에서 수정/수집 시점을 확인할 수 있습니다. 설명을 현재 능력 카드 기준으로 추출하고 JSON/SQLite로 구조화했으며, 모드 선택과 일부 공식 대조 주석을 추가했습니다.

검증 출처: Blizzard Entertainment의 공식 Overwatch 패치노트 — https://overwatch.blizzard.com/en-us/news/patch-notes/

공식 변경 수치는 해당 `official_checks[].source_url`에 연결했습니다. 공식 패치 문단 전체를 배포 데이터에 복제하지 않았습니다. 한국어 영웅 표시명은 OverFast API — https://overfast-api.tekrop.fr/ — 에서 확인했습니다.

Overwatch와 캐릭터에 관한 권리는 각 권리자에게 있습니다. 이 데이터는 팬 프로젝트용 수집/정리 결과이며 Blizzard의 공식 인증 데이터가 아닙니다. 게임 이미지·영상·음성은 묶음에 포함하지 않았습니다.
